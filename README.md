# موقع ارض اليرموك

موقع مؤسسي متعدد الصفحات بالعربية والإنكليزية، باستخدام PHP وMySQL. المحتوى مأخوذ من الملف التعريفي المرفق، والشعار الأصلي محفوظ دون تعديل. يعرض الخادم الصفحات كاملة؛ JavaScript يحسن القائمة والقطاعات ويشغل عارض PDF المحلي.

## GitHub وتنزيل المشروع

المستودع الخاص: [Moh989/ard-alyarmwk](https://github.com/Moh989/ard-alyarmwk). تعليمات الاستنساخ عبر Git LFS وتنزيل الحزمة الجاهزة في [دليل GitHub](docs/GITHUB.md).

## التسليم لمسؤول الاستضافة

ابدأ بـ [تعليمات التسليم والرفع](docs/deployment/HANDOFF.md). قالب `config/production.example.php` يتضمن وجهة الإشعارات التي حددها المالك دون كلمات مرور. ملف المقارنة [العربية والإنكليزية](docs/bilingual-review.html) جاهز لاعتماد الشركة قبل إطلاق النسختين. فحص التجهيز: `php bin/check-launch.php`.

## المعاينة الجاهزة في هذا الجهاز

- العربية: http://127.0.0.1:8088/ar/
- English: http://127.0.0.1:8088/en/
- لوحة الإدارة: http://127.0.0.1:8088/admin
- إدارة السلايدرات المستقلة لكل صفحة وقطاع ولغة: http://127.0.0.1:8088/admin/sliders
- بيانات المسؤول الأول العشوائية موجودة محلياً في `storage/initial-admin.txt` بصلاحية قراءة خاصة. غيّر كلمة المرور من اللوحة بعد الدخول، ثم احذف هذا الملف. ليس جزءاً من حزمة التسليم.
- لإعادة تشغيل المعاينة، افتح `معاينة الموقع.command` أو شغّل `./bin/preview.sh`. اترك نافذة الخادم مفتوحة. لا يشغل البرنامج خدمات على الإنترنت.

المعاينة تستخدم قاعدة MySQL مستقلة داخل `storage/mysql` على المنفذ 3308، بينما يبقى خادم المواهب على 3307. يقرأ مشغّل المعاينة المنفذ من `config/local.php` ويتحقق من اتصال قاعدة الموقع قبل تشغيل خادم محلي؛ يرفض تهيئة قاعدة بديلة عند غياب البيانات. لا تنقل مجلد قاعدة التشغيل المحلية إلى خادم الإنتاج؛ أنشئ قاعدة جديدة بالمخطط والبذور أدناه. قاعدة البيانات ومفاتيح الإعداد ليست ضمن الأرشيف.

## متطلبات التشغيل

اختُبر فعلياً على macOS باستخدام PHP **8.5.7** وMySQL **9.7.1** وNode **24.16.0** ومتصفحي Chrome وWebKit 26.6 عبر Playwright **1.63.0**. الكود يستهدف PHP 8.2+ وMySQL 8.0+؛ التوافق مع هذه الإصدارات الدنيا وMariaDB لم يختبر في هذه البيئة.

امتدادات PHP: `pdo`, `pdo_mysql`, `mbstring`, `fileinfo`, `gd`, `openssl`, `zip`, `session`, `json`. للملفات: `upload_max_filesize=40M`, `post_max_size=42M`, `memory_limit=256M` أو أكثر. `gd` مع WebP وPNG مطلوب لمعالجة الصور. لا يحتاج الموقع إلى خادم Node في التشغيل؛ Node مخصص للاختبارات وتجهيز عارض PDF.

اعتماد البريد: PHPMailer **6.12.0**، مثبت بالإصدار المقفل في `composer.lock`. عارض الملف: PDF.js **6.3.289**، وأصوله الجاهزة محلية داخل `public/assets/pdfjs` مع الرخصة. الخط المحلي IBM Plex Sans Arabic يشمل محارف لاتينية متوافقة ضمن عائلة IBM Plex ورخصة SIL OFL مرفقة.

## تثبيت نسخة جديدة

1. فك المشروع في مجلد خارج جذر الويب؛ اجعل **`public/` وحده** Document Root.
2. أنشئ قاعدة ومستخدم MySQL بكلمة مرور قوية عبر أدوات إدارة الخادم. مثال SQL، مع استبدال كلمة المرور قبل التنفيذ:

```sql
CREATE DATABASE ard_alyarmwk CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'ard_app'@'localhost' IDENTIFIED BY '<GENERATE-A-STRONG-PASSWORD>';
GRANT SELECT, INSERT, UPDATE, DELETE, CREATE, ALTER, INDEX, REFERENCES
ON ard_alyarmwk.* TO 'ard_app'@'localhost';
```

3. انسخ `config/config.example.php` إلى `config/local.php`. اضبط DSN والمستخدم وكلمة المرور و`base_url`. أنشئ مفتاحاً خاصاً بـ:

```bash
php -r 'echo bin2hex(random_bytes(32)), PHP_EOL;'
```

ضع الناتج في `app_key`. لا تضع أسراراً داخل `public/` أو مستودع Git. احمِ ملف الإعداد بصلاحية `600` أو بمالك PHP المناسب.

4. ثبّت اعتماد البريد وأنشئ المحتوى:

```bash
composer install --no-dev --prefer-dist
php bin/migrate.php
php bin/seed.php
php bin/create-admin.php --email=YOUR-ADMIN-EMAIL
```

أداة المسؤول تطلب كلمة مرور مخفية من 12 حرفاً على الأقل؛ لا توجد كلمة مرور ثابتة في الكود. `seed.php` يرفض إعادة البذر إذا وجد صفحات، لحماية التعديلات. لإنشاء المحتوى الأصلي لا تحتاج Python؛ `database/seed.json` جاهز. `database/build_seed.py` مصدر توليده للتطوير فقط.

5. امنح عملية PHP الكتابة على `storage/` فقط، واحتفظ بباقي الشفرة للقراءة. تُخزن الصور المرفوعة **خارج جذر الويب**، ويقدمها مسار متحقق من الوصول `/media/{id}`. بعد التثبيت اسحب صلاحيات CREATE/ALTER/INDEX/REFERENCES من مستخدم التطبيق، واستخدم مستخدم ترحيلات منفصلاً عند الحاجة.
6. للتشغيل المحلي عدّل الإعداد إلى `env=local`, `session_secure=false`, `require_approved=false`, `mail_transport=log` و`base_url=http://127.0.0.1:8088` ثم:

```bash
php -d upload_max_filesize=40M -d post_max_size=42M -S 127.0.0.1:8088 -t public public/router.php
```

في الإنتاج استخدم HTTPS وPHP-FPM أو Apache. راجع `docs/deployment/nginx.conf` و`public/.htaccess`. الأمثلة تحتاج ملاءمة مسار PHP وشهادة TLS والنطاق؛ لم تُنشر إلى خادم إنتاج في هذه المهمة.

## إعداد البريد

الرسالة تُحفظ في MySQL ويظهر رقمها المرجعي أولاً. إشعار البريد مهمة مستقلة؛ لا يتضمن نص الرسالة أو بيانات صاحبها، بل رقم الطلب ورابط لوحة الإدارة.

- `disabled`: تُحفظ الرسائل دون إشعارات.
- `log`: اختبار محلي يكتب إشعاراً في `storage/mail/`؛ **لا يرسل بريداً حقيقياً**.
- `smtp`: اضبط `smtp.host`, `port`, `encryption` (`tls` للمنفذ 587 أو `smtps` للمنفذ 465), `username`, `password`, `from`, `to` في `config/local.php`. يستخدم PHPMailer التحقق الافتراضي من شهادات TLS.

شغّل العامل دورياً، مثلاً كل دقيقة:

```cron
* * * * * cd /srv/ard-alyarmwk && /usr/bin/php bin/mail-worker.php >> storage/logs/mail-worker.log 2>&1
```

يمكن تشغيل `php bin/mail-worker.php` يدوياً. يعالج حتى 50 إشعاراً في كل دورة، ويحمي نفسه من التشغيل المتزامن. الحالات ظاهرة في اللوحة؛ الإشعار الفاشل يحتاج إعادة جدولة من الرسالة بعد إصلاح الإعداد. لا يعيد إرسال إشعار مرسل. راقب صف انتظار البريد وسجلات الخادم. إعداد SMTP الخارجي والتسليم الحقيقي يحتاجان بيانات مزود البريد ولم يُختبرا.

## الصفحات والروابط

`/ar/` و`/en/`: الرئيسية، `/about`، `/sectors`، ثماني صفحات `/sectors/{slug}`، `/profile`، `/contact`، `/privacy`، وصفحة 404. صفحة `/projects` وتفاصيلها ومعرضها وتصفية قطاعاتها جاهزة وتظهر عندما يوجد مشروع منشور معتمد؛ لا توجد مشاريع مختلقة ضمن البيانات الأولية.

`/sitemap.xml` يولد روابط المحتوى المنشور حسب حالة اللغة. `robots.txt` يمنع فهرسة بيئة `local`. canonical وhreflang وOpen Graph وX وOrganization JSON-LD تتولد من المحتوى والإعداد. حافظ على `base_url` مطابقاً للنطاق المعتمد؛ لا يُشتق من ترويسة Host.

## بنية المشروع

- `app/`: الإعداد المشترك، PDO، الأمان، التحكم العام والإداري، القوالب.
- `public/`: مدخل الويب، CSS وJS، الشعار والصور والخطوط وPDF الأصلي.
- `config/`: إعداد نموذجي وإعداد خاص مستبعد من Git.
- `database/`: مخطط الجداول والمحتوى الأولي الموثق.
- `bin/`: إنشاء قاعدة البيانات والمحتوى والمسؤول وعامل البريد والمعاينة.
- `storage/`: الملفات المرفوعة والسجلات والبيانات المحلية؛ غير قابل للوصول عبر الويب.
- `docs/`: دليل الإدارة ومصادر المحتوى والأصول وتقرير التحقق ومتطلبات النشر.
- `tests/`: اختبارات المتصفح والوصولية والروابط وPDF ونتائجها.

## التطوير والاختبارات

```bash
npm ci
node tests/visual.mjs
node tests/accessibility.mjs
node tests/pdf.mjs
```

الاختبارات تستخدم Chrome الموجود في مسار macOS الافتراضي، ويمكن ضبط `CHROME_PATH` في معظم الأدوات. `npm test` يشغّل `php tests/isolated-browser.php` الذي ينشئ قاعدة اختبار وخادماً وحساب مسؤول مؤقتاً، ثم يحذفها بعد الاختبار. يستخدم اتصال MySQL التطوير الخاص الذي تجهزه المعاينة المحلية؛ لا تنقل بياناته إلى الإنتاج. تشغيل الاختبار الوظيفي المباشر يرفض غياب إعداد البيئة المعزولة. بعض اختبارات الإدارة القديمة تتعامل مع قاعدة المعاينة؛ شغّلها على قاعدة تطوير معزولة فقط. لا يُرسل بريد خارجي في الاختبار المحلي.

أصول PDF.js مضمنة في التسليم. لتحديثها، ثبّت الإصدار المطلوب عبر npm وانسخ `build/pdf.mjs`, `build/pdf.worker.mjs`, `cmaps`, `standard_fonts`, `wasm` ورخصتها إلى `public/assets/pdfjs/` ثم اختبر جميع صفحات الملف.

راجع `docs/ADMIN-GUIDE.md` و`docs/CONTENT-SOURCES.md` و`docs/ASSETS.md` و`docs/TEST-REPORT.md` و`docs/LAUNCH-CHECKLIST.md`.

## سلايدر الصفحات

كل صفحة عامة تتضمن عارض شرائح متجاوباً باللغتين، مع السحب باللمس والأسهم والترقيم. في الرئيسية يبدأ فيلم الشركة، وبعد نهايته تتتابع شرائح الصور تلقائياً كل 6 ثوانٍ مع زر إيقاف واستئناف. الشرائح الافتراضية من محتوى قاعدة البيانات الحالية، ويمكن تخصيص أربع شرائح لكل لغة من محرر الصفحة. لا يلزم أي تغيير في مخطط قاعدة البيانات أو إعادة زرعها. راجع [دليل السلايدر](docs/SLIDERS.md) و[دليل الإدارة](docs/ADMIN-GUIDE.md). للتحقق: `node tests/sliders.mjs`.

الفيديو جاهز ومرفق بنسختي 720p (791 كيلوبايت) و480p (343 كيلوبايت للهاتف)، وصورة معاينة فورية. يختار المتصفح نسخة واحدة عند الحاجة. `php bin/seed.php` يسجله ضمن التثبيت الجديد؛ لتحديث قاعدة قائمة شغّل `php bin/install-video.php --activate` دون إعادة بذرها. راجع [تجهيز الفيديو والتحكم به](docs/VIDEO.md).

## استكمال الملف التعريفي الحالي

غلاف النسخة الأفقية الحالية متزامن مع الملف الحقيقي، والمعاينة تدعم تحميل أجزاء PDF عند الحاجة. يبقى الملف الأصلي كاملاً دون تعديل. لتطبيق الغلاف الجاهز على قاعدة المعاينة القائمة: `php bin/sync-profile.php --activate`؛ التثبيت الجديد يستخدم البذور المحدثة مباشرة. تفاصيل النسخة الحالية وحد الرفع في [دليل الإدارة](docs/ADMIN-GUIDE.md). اختبار المطابقة والتحميل والتجاوب: `node tests/profile-current.mjs`.

## تحديث تجهيز الإطلاق — 13 أيلول 2026

تستخدم المعاينة والتنزيل نسخة PDF خفيفة بحجم 4.2 MB مع رابط للأصل 107 MB. بعد نقل الملفات شغّل `php bin/install-profile-web.php`؛ [تفاصيلها](docs/PROFILE-WEB.md). أدوات النسخ والاستعادة وفحص الاستضافة مرفقة؛ راجع [دليل النسخ الاحتياطي](docs/BACKUP-RESTORE.md). نجح الفحص المحلي على Chrome وWebKit، ولا يزال اختبار الاستضافة والبريد الفعلي واعتماد الشركة مطلوباً قبل النشر.

## النمط النهاري والليلي

زر الشمس/القمر بجانب اللغة يبدّل المظهر ويحتفظ باختيار الزائر محلياً. يشمل الصفحات والقائمة المنسدلة والنماذج والإدارة وواجهة عارض PDF مع إبقاء الملف والصور بألوانها الأصلية. يبدأ بإعداد الجهاز حتى يختار الزائر يدوياً. تفاصيل التهيئة والخصوصية والاختبار في [دليل الأنماط](docs/THEMES.md). لتحديث سياسة الخصوصية في قاعدة قائمة: `php bin/sync-theme-privacy.php`.
