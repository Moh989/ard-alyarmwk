# فيلم الشركة داخل السلايدر

أُدرج `Comp 1.mp4` في أول شريحة بالرئيسية في العربية والإنكليزية، دون قص الشعار أو الاسم المدمجين في المادة الأصلية. تبقى عناوين الواجهة وأزرارها نصوص HTML. الفيلم صامت من المصدر، وتصنيفه «مشاهد توضيحية»؛ ليس توثيقاً لمشروع محدد.

## الحجم والتحميل

| الملف | الأبعاد | الحجم الفعلي |
|---|---|---|
| الأصل المحفوظ محلياً | 3840×2160 | 19,549,366 بايت |
| نسخة الحاسوب | 1280×720 | 790,697 بايت، أقل بنحو 96% |
| نسخة الهاتف | 854×480 | 342,850 بايت، أقل بنحو 98% |
| صورة المعاينة | 1280×720 / 640×360 | 30,170 / 8,970 بايت |

مدة الأصل 10.54 ثانية؛ نسخ الويب 10.5 ثانية بسبب تحويل معدل الإطارات إلى 24fps. ترميز H.264 High Level 3.1 / yuv420p / CRF 25 و26، مع `faststart`: بيانات MP4 الوصفية في بداية الملف. البصمات والمسارات في `database/video-seed.json`. قياس SSIM للنسخة 720p بلغ 0.990480 مقابل مرجع مصغر إلى نفس الدقة ومعدل الإطارات، وليس مقياساً مطلقاً لجودة الأصل 4K.

يظهر WebP أولاً. عنصر الفيديو `preload=none` ولا يُعطى مصدر تحميل إلا عند اختيار الشريحة وظهورها. يختار JavaScript ملفاً واحداً: 480p عند عرض ≤700px أو توفير البيانات، و720p لباقي الشاشات. لا تُحمّل النسختان معاً. الفيديو صامت ويعمل داخل الصفحة `playsinline`؛ يتوقف عندما يخرج من الشاشة أو تنتقل إلى شريحة أخرى أو تخفي علامة التبويب.

الملفات تقدم محلياً عبر `/media/{id}` مع Range 206، والتحقق من النطاقات، والتخزين المؤقت، والتحقق من صلاحية عرض الوسيط. الوصول المباشر إلى `/assets/video/` محجوب في PHP router وأمثلة Apache وNginx المرفقة. طبّق قواعد الخادم المرفقة عند النشر. تستخدم أسماء الملفات بصمة المحتوى لتجنب تقديم نسخة قديمة.

## التتابع والتحكم

- انتظار حدث `ended` الفعلي: الفيديو يعرض مرة كاملة، ثم يبدأ تتابع الصور كل 6 ثوانٍ. عند العودة إليه يبدأ من الصفر.
- زر داخل الفيلم يوقف الفيديو ويستأنفه. إيقافه يبقي الشريحة ولا يختصر الفيلم.
- زر دائري مستقل مع أزرار الشرائح يوقف **التنقل التلقائي** ويستأنفه. يمكن للفيديو أن يكمل ويقف على آخر إطار عند إيقاف التنقل؛ استئنافه بعد النهاية ينقل إلى الصورة التالية.
- عداد الصور يتوقف خارج الشاشة وعند إخفاء علامة التبويب، ويبدأ مدة كاملة عند العودة. مؤشر برتقالي صغير يوضح مدة الصور.
- التركيز بلوحة المفاتيح يوقف التتابع حتى يضغط الزائر زر استئنافه. لا تُعلن التغييرات التلقائية في منطقة `aria-live`.
- تفضيل الحركة المخففة أو توفير البيانات يبدأ بصورة ثابتة دون تحميل فيديو ودون تتابع. زر تشغيل الفيديو أو التتابع يتيح طلب التشغيل صراحة. رفض المتصفح التشغيل التلقائي يبقي الصورة وزر التشغيل؛ لا تقفز الشرائح قبل انتهاء فيلم لم يُشغّل.
- السلايدر الذي لا يحتوي فيديو يبقى يدوياً. شريحة فيديو منفردة تعرض مرة واحدة وتتيح إعادة التشغيل، دون أزرار تنقل غير فعالة.
- دون JavaScript يتاح رابط إلى `/video-viewer` بمشغل المتصفح الأصلي والتحكم اليدوي. عند فشل تحميل الفيديو تبقى الصورة ويظهر رابط البديل. صفحة المشغل تحترم صلاحيات نشر الفيديو ولا تُفهرس.

## الإدارة والتثبيت

الفيديو جاهز في حزمة التسليم. لا يحتاج التشغيل إلى Python أو FFmpeg. التثبيت الجديد بـ`php bin/seed.php` يسجله بعد المحتوى الأولي. لإضافة الأصول الجاهزة إلى قاعدة قائمة:

```bash
php bin/install-video.php --activate
```

يتحقق الأمر من بصمات الملفات ويضيف الوسائط إن لم تكن مسجلة. يحفظ الربط في `settings.video_variants` واختيار الرئيسية في `home_video_id`. لا يمس نصوص الصفحات أو شرائحها. دون `--activate` يحافظ على اختيار الرئيسية الموجود. لا ترحيل SQL مطلوب.

من لوحة «الإعدادات» اختر «فيديو الواجهة الرئيسية». اختيار «بدون فيديو» يخفيه. من محرر الصفحة يمكن اختيار فيديو مسجل لأي شريحة مخصصة وحالة نشر لكل لغة. حقل `translations.body.slider[].video_id` اختياري؛ تُختار صورة المعاينة تلقائياً إن كانت الصورة فارغة. تخصيص شرائح منشورة يستبدل شرائح الصفحة الافتراضية. المسودات لا تتيح الفيديو أو نسخه للزائر، إلا إذا كان مستخدماً أيضاً في محتوى منشور آخر.

## تجهيز فيلم بديل

أداة التجهيز مخصصة لفيلم صامت قصير، وترفض صوتاً أو مدة تتجاوز 30 ثانية لتجنب معالجة مادة مختلفة دون مراجعة. ضع الفيلم خارج `public/` ثم:

```bash
python3 -m venv .venv
.venv/bin/pip install Pillow imageio-ffmpeg==0.6.0
.venv/bin/python bin/optimize-video.py 'Comp 1.mp4'
php bin/install-video.php --activate
```

يمكن استخدام FFmpeg مثبت مسبقاً عبر `--ffmpeg /path/to/ffmpeg`. اختُبر التجهيز بـFFmpeg 7.1. تولد الأداة MP4 بأسماء جديدة وصور معاينة وتحدث manifest. راجع النصوص البديلة والمصدر في مكتبة الوسائط إذا تغير موضوع الفيلم. لا يُرفع MP4 خام من نموذج رفع الصور/PDF، ولا يجري تحويل فيديو مكلف داخل طلب PHP.

الأصل `Comp 1.mp4` بقي دون تعديل في مجلد المشروع، ولا يدخل حزمة المصدر؛ الحزمة تشمل نسخ الويب المستخدمة كاملة.

## التحقق

`tests/video.mjs` يفحص التشغيل والتحميل والبدائل وإدارة الفيديو وصلاحياته. `tests/video-autoplay.mjs` يختبر نهاية فعلية للفيلم ودورة الصور وإعادة البداية وإيقاف/استئناف التتابع وتفضيلات المستخدم. `tests/video-native.mjs` يضغط زر المشغل الأصلي دون JavaScript. `tests/video-preview.mjs` ينتج لقطات العربية والإنكليزية على 375/768/1440. نتائج JSON في `tests/`، والحدود المعلنة في `TEST-REPORT.md`.
