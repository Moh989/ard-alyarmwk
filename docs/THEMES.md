# النمط النهاري والليلي

زر الشمس/القمر بجانب اختيار اللغة يبدّل النمط دون إعادة تحميل الصفحة. يظهر باللغتين على الهاتف والتابلت والكمبيوتر، وفي الإدارة ومشغلي PDF والفيديو أيضاً. أسماء الزر وإرشاداته تتبع لغة الواجهة.

عند أول زيارة يُستخدم إعداد الجهاز `prefers-color-scheme`. بعد اختيار الزائر يدوياً، يُحفظ `light` أو `dark` في `localStorage` تحت المفتاح `ard-theme`، ويُقدَّم على إعداد الجهاز. يستمر الاختيار عبر الصفحات واللغات والزيارات والتبويبات من المتصفح نفسه. لا يُرسل إلى الخادم ولا يرتبط بحساب أو رسالة تواصل. يمكن الرجوع إلى متابعة إعداد الجهاز بمسح بيانات الموقع في المتصفح.

إذا منع المتصفح التخزين، يبقى الزر فعالاً في الصفحة دون ضمان حفظ الاختيار لزيارة لاحقة. دون JavaScript تتبع الألوان إعداد الجهاز باستخدام CSS وتُخفى أزرار التبديل غير القابلة للتشغيل. تظل الروابط والقائمة المنسدلة تعملان.

## التنفيذ والتطوير

- `app/views/theme-head.php`: ملف تهيئة صغير متزامن قبل أوراق CSS لتطبيق الاختيار قبل العرض، مع بيانات لون المتصفح. لا يحتاج استثناء CSP أو JavaScript ضمن HTML.
- `app/views/theme-toggle.php`: زر دلالي مع أسماء وصول عربية/إنكليزية وأيقونتي SVG. لا يرسل النماذج ولا يغير البيانات المكتوبة.
- `public/assets/theme.js`: قراءة الاختيار، تغييرات إعداد الجهاز، التخزين ومزامنة التبويبات، ومزامنة عارض PDF من الصفحة الأصلية ضمن النطاق نفسه فقط. يعاد التحقق عند الرجوع إلى صفحة محفوظة في ذاكرة المتصفح.
- `public/assets/theme.css`: ألوان الأسطح والنصوص والحدود والحالات، وتكييف القوائم والسلايدر والنماذج والإدارة. تبقى ألوان العلامة التجارية والصور والفيديو وورق PDF الأصلية دون قلب أو فلاتر ليلية. الطباعة بخلفية فاتحة.

روابط ملفات النمط تتضمن بصمة المحتوى لتحديث التخزين المؤقت عند تعديلها. لا توجد مكتبة إضافية أو اتصالات خارجية. تُحترم إعدادات تقليل الحركة.

## تحديث قاعدة قائمة

لا يحتاج المظهر إلى تغيير مخطط قاعدة البيانات. حدّث الملفات، ثم أضف بيان حفظ التفضيل إلى سياسة الخصوصية الموجودة:

```sh
php bin/sync-theme-privacy.php
```

يضيف الأمر جملة في العربية والإنكليزية مرة واحدة ويحافظ على بقية النصوص وحالات الاعتماد. بيانات التثبيت الجديد تتضمنها. لتجديد المقارنة الداخلية بعد التحديث: `php bin/export-review.php`.

التحقق: `node tests/theme.mjs`، والتفاصيل في `tests/theme-results.json` و`docs/TEST-REPORT.md`. لقطات المعاينة المختارة في `docs/preview/`.
