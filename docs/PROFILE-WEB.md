# نسخة قراءة خفيفة للملف التعريفي

أُنتجت في 13 أيلول 2026 من الأصل الحالي، دون تعديل الأصل أو عدد صفحاته. الحجم **4,152,977 بايت (4.2 MB)** بدلاً من **106,978,045 بايت (107 MB)**؛ انخفاض 96.12%. النسخة الأصلية الكاملة متاحة برابط مستقل في صفحة الملف.

أزيلت بيانات تحرير Illustrator الخاصة والمصغرات والكائنات غير المستخدمة. أُعيد ضغط تسع صور JPEG بجودة 88 مع إبقاء أبعادها؛ النصوص المتجهية والشعار وأبعاد الصفحات محفوظة. تطابق النص المستخرج صفحة بصفحة، وراجعت الصفحات العشر بصرياً بعد التحويل. سجّل `tests/profile-compression-results.json` فروق الصور المرندرة؛ متوسط الفرق لكل قناة أقل من 1 على مقياس 255 لكل صفحة. لا تعني إعادة الضغط تطابق البايتات مع الأصل.

المصدر ومعايير المعالجة والبصمات في `database/profile-web.json`. أداة التطوير pypdf 6.18.1 وفق [توثيق تصغير الملفات الرسمي](https://pypdf.readthedocs.io/en/stable/user/file-size.html). لا يحتاج خادم الموقع إلى Python أو pypdf لتقديم النسخة الجاهزة.

## التركيب والتحديث

التثبيت الجديد `php bin/seed.php` يسجل النسخة تلقائياً. بعد نقل الملفات إلى خادم جديد، أو لتحديث قاعدة قائمة:

```sh
php bin/install-profile-web.php
```

يتحقق الأمر من SHA-256 للأصل والنسخة الخفيفة قبل تسجيلهما، ولا يعيد بذر النصوص. ترتبط النسخة برقم الأصل ومساره وحجمه وتاريخ تعديله؛ عند اختيار PDF آخر في الإدارة أو استبدال الأصل على القرص، يعود الموقع إلى الملف المحدد حتى تُجهز نسخة مطابقة. بعد استبدال الأصل، حدّث الغلاف أيضاً؛ تعليمات ذلك في دليل الإدارة.

لإنتاج نسخة جديدة على جهاز التطوير:

```sh
python3 -m venv .venv
.venv/bin/pip install pypdf==6.18.1 Pillow==12.3.0
.venv/bin/python bin/optimize-profile.py
```

الأداة مخصصة للملف الحالي غير التفاعلي. راجع كل صفحة والنصوص والمصدر والأبعاد قبل تثبيت أي ناتج جديد. الناتج المستقل `output/pdf/company-profile-web.pdf`، وأصل العرض ذو اسم مبني على البصمة داخل `public/assets/profile/`، وبياناته في `database/profile-web.json`.

مسار `/assets/profile/` محجوب مباشرة بقواعد الخادم؛ يقدم `/media/{id}` الملف المرتبط بالنشر مع HTTP Range. حافظ على هذه القواعد، ولا تضغط استجابات PDF/MP4 بضغط HTTP يغير نطاقات البايت. إذا تعذر العارض، يبقى التنزيل ممكناً دون JavaScript.
